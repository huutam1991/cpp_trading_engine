# CPP trading engine
My personal trading engine project, using C++, I build every core features in this project including: **Json** class, **coroutine model**, **https server** + **API system**, **mongoDB** integration, ....


# Build command (Linux)
```
./install_library.sh
./build_bash.sh
```

# Run command  (Linux)
```
./run_bash.sh
```
